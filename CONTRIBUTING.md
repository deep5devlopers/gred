# Contributing to Gred by Deep

We welcome community pull requests and contributor pairings!

## How to Contribute
1. Fork the repository `deep5devlopers/gred`.
2. Create your feature branch (`git checkout -b feat/your-feature`).
3. Commit with co-authored trailers honoring the project leads:
   ```
   Co-authored-by: Deep Sanchaniya <deep-00007@users.noreply.github.com>
   Co-authored-by: deep5devlopers <deep5devlopers@gmail.com>
   ```
4. Push to branch and open a Pull Request.
5. Invariant benchmarks will automatically evaluate topological execution speed (< 12ms).
